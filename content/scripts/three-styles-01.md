# 3 Claude Code skills = 3 motion design styles

Pillar: `claude-code` – nauja serija „video kūrimas su Claude Code“
(vėliau tiltas į TikMaker: skill'ai saugomi, renkiesi, redaguoji vienoje vietoje).

Kaip daroma:
1. TikMaker agentas sugeneruoja video įprastu stiliumi (`clear` arba
   `depth`) ir palieka 3 tuščias vietas (recording slot) animacijoms.
2. Trys animacijos – atskiri klipai (atskiros Remotion kompozicijos → mp4),
   kuriuos padarome atskirai.
3. Klipai įkeliami į tas vietas redaktoriuje.

## Idėja agentui (įklijuoti į Start)

```
A video showing that Claude Code can make motion design for you.
Hook: "I asked Claude Code for wow animations. No After Effects."
Then 3 Claude Code skills – each one turns your video into a completely
different motion design style (01, 02, 03, each with a short name).
For each of the 3 styles, leave a big recording slot – I will add a ready
~5 second animation clip made in that style. Do NOT draw the animations
yourself: the scene is the frame around the clip (the style's number and
name), the clip is the star, as big as possible.
One fact before the end: a skill is just one markdown file that Claude
reads before it draws every scene.
CTA: comment "SKILL" and I'll send you the prompts.
```

## Animacijų klipai (daromi atskirai)

Kiekvienas ~5 s, 9:16 (arba tokio formato, kokį paliks agento vieta),
be jokios prasmės – grynas judesys, perėjimai, „satisfying“.
Stiliai parenkami, kai agentas paruoš šabloną (pagal jo pavadinimus 01–03).
